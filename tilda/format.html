Форматирование текста

Чтобы применить форматирование текста в чате, перед текстом сообщения напишите подходящий тег.

Как это работает

В начале сообщения поставьте код тега и напишите текст сообщения. Для быстрого использования перечисленных тегов используйте кнопку «Копировать».

Возможности

1. Цвет текста

Сообщение определённого цвета. Два варианта записи:

Код 
<color=#FF1493>
Пример

На этой неделе грабим грузовики 97 сервера.

Код 
<#1A8F4A>
Пример

У кого-нибудь есть С?

Можно использовать несколько тегов в одном сообщении, например сделать градиент:

Код 
<#FF0000>а <#FF6600>м<#FF9900>о<#FFCC00>ж<#FFFF00>н<#CCFF00>о <#66FF00>д<#33FF00>е<#00FF00>л<#00FF33>а<#00FF66>т<#00FF99>ь <#00FFFF>т<#00CCFF>а<#0099FF>к <#0033FF>е<#2B00FF>щ<#5500FF>ё
Пример

а можно делать так ещё

2. Подчёркнутый

Тег в начале сообщения делает текст подчёркнутым.

Код 
<u>
Пример

Важно! Свой сервер грабить нельзя!

3. Перенос строки

Вставьте \n там, где нужен перенос на новую строку внутри одного сообщения.

Код 
\n
Пример

текст первой строки
текст второй строки

4. Жирный

Тег в начале сообщения делает текст жирным.

Код 
<b>
Пример

Жирный текст сообщения

5. Курсив

Тег в начале сообщения делает текст курсивом.

Код 
<i>
Пример

Курсивный текст сообщения

6. Зачёркнутый

Тег в начале сообщения зачёркивает текст.

Код 
<s>
Пример

Зачёркнутый текст сообщения

7. Упоминание игрока

Напишите @ и сразу после неё имя игрока. Так можно его тегнуть в чате.

Код 
@
Пример

@ИмяИгрока привет, зайди в сбор!
