Бесплатный телепорт

Вы можете использовать бесплатный телепорт, чтобы выровнять базу на своём сервере. Для этого в субботу слетайте к врагу, а при возвращении выберите новое место для базы бесплатно. Подробнее ниже.

Когда это работает

Полёт к врагу и возвращение домой бесплатны только в специальном временном окне.

Время сервера сб. 00:00 — вс. 00:00
Москва (MSK) сб. 05:00 — вс. 05:00

Шаги

1

В правом вертикальном ряду нажмите на иконку VS (она последняя в списке)

Место для скриншота — положите файл в assets/screenshots
2

Перейдите на третью вкладку Рейд

Место для скриншота — положите файл в assets/screenshots
3

Нажмите кнопку Вперёд. Это переместит вас на сервер противника

Место для скриншота — положите файл в assets/screenshots
4

Поставьте базу на карте противника

Если у вас есть щит — место неважно. Если щита нет — ставьте подальше от вражеских баз, чтобы вас не атаковали сразу же.
Место для скриншота — положите файл в assets/screenshots
5

Сверху по центру на надписи «Боевая зона S…» нажмите иконку стрелки назад. Это переместит вас обратно на ваш сервер

Место для скриншота — положите файл в assets/screenshots
6

Поставьте базу на карте своего сервера в желаемом месте

Откроется карта домашнего сервера. Поставьте вашу базу впритык к соседним базам, выравнивая её по горизонтали и вертикали относительно других баз. Для выравнивания по вертикали удобно ориентироваться по табличкам с именами.

Если в вашем альянсе еще нет строгого построения, ориентируйтесь на первые колонки, так как последние могут быть поставлены неровно и вы лишь продолжите неправильное расположение баз.
Скриншот: правильное размещение на 98

Как выбрать место дома

Плохо

Хорошо

  • ✓ Впритык к соседним базам альянса
  • ✓ Ровно по горизонтали и вертикали относительно других баз
  • ✓ Ориентируйтесь на первые колонки
  • ! Не забудьте вернуться домой до конца бесплатного временного окна

Если базу сожгли

Когда вашу базу сжигают дотла, вы автоматически перемещаетесь в случайное место на карте. Используйте описанный выше порядок действий, чтобы вернуться на прежнее место бесплатно.

Чтобы этого избежать, устанавливайте щит так, чтобы он точно держался до вс. 05:00 МСК (вс. 00:00 серверного времени).

Форматирование текста

Чтобы применить форматирование текста в чате, перед текстом сообщения напишите подходящий тег.

Как это работает

В начале сообщения поставьте код тега и напишите текст сообщения. Для быстрого использования перечисленных тегов используйте кнопку «Копировать».

Возможности

1. Цвет текста

Сообщение определённого цвета. Два варианта записи:

Код 
<color=#FF1493>
Пример

На этой неделе грабим грузовики 97 сервера.

Код 
<#1A8F4A>
Пример

У кого-нибудь есть С?

Можно использовать несколько тегов в одном сообщении, например сделать градиент:

Код 
<#FF0000>а <#FF6600>м<#FF9900>о<#FFCC00>ж<#FFFF00>н<#CCFF00>о <#66FF00>д<#33FF00>е<#00FF00>л<#00FF33>а<#00FF66>т<#00FF99>ь <#00FFFF>т<#00CCFF>а<#0099FF>к <#0033FF>е<#2B00FF>щ<#5500FF>ё
Пример

а можно делать так ещё

2. Подчёркнутый

Тег в начале сообщения делает текст подчёркнутым.

Код 
<u>
Пример

Важно! Свой сервер грабить нельзя!

3. Перенос строки

Вставьте \n там, где нужен перенос на новую строку внутри одного сообщения.

Код 
\n
Пример

текст первой строки
текст второй строки

4. Жирный

Тег в начале сообщения делает текст жирным.

Код 
<b>
Пример

Жирный текст сообщения

5. Курсив

Тег в начале сообщения делает текст курсивом.

Код 
<i>
Пример

Курсивный текст сообщения

6. Зачёркнутый

Тег в начале сообщения зачёркивает текст.

Код 
<s>
Пример

Зачёркнутый текст сообщения

7. Упоминание игрока

Напишите @ и сразу после неё имя игрока. Так можно его тегнуть в чате.

Код 
@
Пример

@ИмяИгрока привет, зайди в сбор!

Нашли ещё тег?

Если обнаружите другие рабочие теги форматирования — напишите, добавим в гайд.
